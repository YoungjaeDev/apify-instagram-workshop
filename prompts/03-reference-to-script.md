# 03. Reference to Script

## 입력

- Channel DNA: `<CHANNEL_DNA_FILE>`
- 레퍼런스 Reel: `<REFERENCE_URL>`
- 새 콘텐츠 주제 또는 제품: `<TOPIC_OR_PRODUCT>`
- 목표 길이: `<DURATION_SECONDS>`

## 요청

1. 레퍼런스의 표현을 복제하지 않고 다음 구조만 추출한다.
   - hook
   - tension 또는 problem
   - demonstration
   - payoff
   - CTA
2. Channel DNA에서 확인된 문장 길이, 전개 순서, CTA 패턴을 적용한다.
3. 레퍼런스에 없는 사실, 제품 효능, 가격, 수치를 만들지 않는다.
4. 다음 세 가지를 생성한다.
   - 구조 요약
   - 촬영 가능한 장면별 대본
   - Instagram caption 초안
5. 참고한 구조와 새로 만든 표현을 구분해 설명한다.
6. 결과를 `results/script-<TOPIC>-<YYYYMMDD>.md`에 저장한다.

저작권을 회피한다고 표현하지 않는다. 레퍼런스의 아이디어 구조를 분석하고 독립적인 표현으로 재구성한다.
